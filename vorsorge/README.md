# Vorsorge ist besser als Nachsorge

Eigenständiger 30-Tage-Planer. Erwachsene/Kinder einstellen, Sollmengen berechnen. Pro Person, pro Erwachsenem, pro Kind oder pro Haushalt. Istwerte bleiben bei Neuberechnung erhalten. Eigene Einträge mit Berechnungsbasis. Speicherung lokal im Browser unter vorsorge-30-v1, JSON-Export und Import inklusive Haushaltsprofil.

30 Tage sind ein gewähltes Planungsziel. Portionszahlen sind keine Nährwertberechnung. Quellen und Annahmen im Dialog. Keine persönlichen Familiendaten.
